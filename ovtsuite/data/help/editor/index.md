# Editor reference

Everything about working on a project's binaries in the main window, one
topic per page.
For a tour of the window itself, start with [The main window](../interface.md);
for undo, saving, checksums and version history, see [Editing and
saving](../editing.md).

| Page | Covers |
|---|---|
| [Tables and editing values](tables-and-editing.md) | Reading a table and its notes, typing values, **Modify selection**, **Fill**, **Smooth**, **Heatmap**, swapping axes, copy and paste, copying a table from another tab. |
| [Comparing files](comparison.md) | The original as read as a tab's comparison, other comparisons (a binary, another tab, a saved version, another project), how differences show, **Edit > Show differences...**. |
| [The Find panel](search.md) | Searching by name, value, address or byte pattern, in one tab or all of them. |
| [3D surface](3d-surface.md) | Viewing a map, and its comparison, as a surface. |
| [Patches](patches.md) | Making a patch from two binaries or from a branch's history, keeping it in the project, applying it to another binary, removing it. |
| [Hex editor](hex-editor.md) | The raw bytes: reading, finding, editing, regions. |
| [Files and formats](files-and-formats.md) | Opening projects, importing files and what each becomes in a project, drag and drop, **File information**. |
| [Exporting](export.md) | Plain binaries, the original factory file, XDF definitions, logs, patches and attachments. |
| [Tabs and sessions](tabs-and-sessions.md) | Tabs, one window or several, the project history, reopening last session's projects, recent projects, closing with unsaved changes. |
| [Keyboard shortcuts](keyboard-shortcuts.md) | Every key, in one table. |
